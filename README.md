# Git and GitHub Practical Record

## 📌 About the Project
This repository contains practical exercises for learning Git and GitHub. It covers repository creation, version control, branching, merging, remote repositories, collaboration, and project management.

## 🎯 Objectives
- Understand Git basics and version control.
- Track file changes and save commits.
- Create, switch, and delete branches.
- Resolve merge conflicts.
- Use GitHub to share and manage repositories.
- Collaborate with other contributors.

## 🧪 Practical Exercises

### 1. Create a Git Repository
Initialize a local Git repository using `git init` and check its status.

### 2. Create a File and Track Changes
Create a text file and stage it using `git add`.

### 3. Commit Changes
Save staged changes in the repository using `git commit`.

### 4. View Commit History
View commit details using `git log` and `git log --oneline`.

### 5. Undo Changes
Discard unwanted, unstaged changes using `git restore`.

### 6. Create, Switch, and Delete a Branch
Practice branch management using `git branch`, `git switch`, and `git branch -d`.

### 7. Resolve a Merge Conflict
Modify the same file in different branches, merge them, and resolve conflicts.

### 8. Store and Restore Changes Using Git Stash
Temporarily save and restore uncommitted changes using `git stash`.

### 9. Configure a Remote Repository
Connect a local repository to GitHub using `git remote add origin`.

### 10. Clone, Push, and Pull Changes
Clone a repository and synchronize changes using `git clone`, `git push`, and `git pull`.

### 11. Fork a Repository and Create a Pull Request
Fork an existing repository, make changes, and submit a pull request.

### 12. Collaborative Editing
Work with another contributor by sharing a repository and synchronizing changes.

### 13. Manage GitHub Issues and Project Boards
Create issues and use GitHub Projects to organize and track tasks.

## 🛠️ Tools Used
- Git
- GitHub
- Terminal / Command Prompt
- Visual Studio Code (optional)

## 💻 Basic Git Commands

```bash
git init
git status
git add .
git commit -m "Initial commit"
git log --oneline
git branch
git switch main
git remote -v
git push origin main
git pull origin main
```

## 📚 Learning Outcomes
After completing these exercises, learners will understand basic version control, repository management, branching, merging, remote synchronization, and collaborative development.

## ✅ Conclusion
These practical exercises provide hands-on experience with Git and GitHub and help build a foundation for software development and team collaboration.
